   $ python3 -m venv venv
   $ source venv/bin/activate
   $ pip install -r requirements.txt

   $ cp .env.example .env

3. Run:
   $ uvicorn main:app --reload --port 8000

4. Test:
   $ curl http://localhost:8000/health

1. BODY SCAN → ML Kit detects 33 pose landmarks
                ↓
2. GENERATE → Python creates 3D mesh (6890 vertices)
                ↓
3. EXPORT → GLB model uploaded to Firebase Storage
                ↓
4. DISPLAY → Flutter renders with model_viewer_plus

30 DAYS LATER...

5. NUTRITION → Track meals (carbs, protein, fats)
                ↓
6. CALCULATE → BMR, TDEE, muscle gain, fat loss
                ↓
7. MORPH → Update 3D mesh with new physique
                ↓
8. COMPARE → Side-by-side before/after

┃ 📊 BODY COMPOSITION FORMULAS                                           ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

BMR (Mifflin-St Jeor):
  Male:   (10 × weight) + (6.25 × height) - (5 × age) + 5
  Female: (10 × weight) + (6.25 × height) - (5 × age) - 161

TDEE: BMR × Activity Multiplier
  Sedentary: 1.2  |  Light: 1.375  |  Moderate: 1.55
  Active: 1.725   |  Very Active: 1.9

Muscle Gain: max 0.25 kg/week (beginners)
  Actual = Max × Protein_Efficiency × Calorie_Factor

Fat Change: Net_Calories / 7700 (calories per kg fat)
